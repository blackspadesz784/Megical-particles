# 📖 Overview

Gesture Controlled 3D Particles is an interactive web application that transforms hand gestures into dynamic 3D particle animations in real time.

Using your webcam, the application detects hand landmarks with **MediaPipe** and morphs thousands of particles into beautiful shapes while allowing users to rotate the scene and change particle colors through natural gestures.
